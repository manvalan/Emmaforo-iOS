# Emmaforo iOS

App SwiftUI per la lampada Emmaforo. Quattro schermate: Semaforo, Colori, Configurazione, Info. Il Bluetooth è il collegamento normale. Il Wi‑Fi, sulla rete già salvata, entra solo quando la scheda è fuori portata.

Il progetto da aprire è `EmmaForo.xcodeproj`.
