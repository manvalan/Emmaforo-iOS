# Emmaforo iOS

App SwiftUI per la lampada Emmaforo. Quattro schermate: Semaforo, Colori, Configurazione, Info. Il Bluetooth è l'unico collegamento con la lampada. La rete Wi‑Fi salvata sulla scheda serve solo a scaricare un firmware nuovo, quando l'app lo segnala e l'utente lo approva; l'app non usa più la rete locale.

Il progetto da aprire è `EmmaForo.xcodeproj`.
